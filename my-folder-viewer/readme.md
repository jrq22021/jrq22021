# 文件夹展示页面

这是一个简单的前端页面，用于上传文件夹并展示其中每个子文件夹中的内容：

- `mk1.jpg/png` 图像
- `mk2.txt` 文本
- `mu1.jpg/png` 图像
- `mu2.txt` 文本

## 📁 使用方式

1. 打开 `index.html` 文件
2. 点击“上传文件夹”按钮（仅支持 Chrome/Edge 浏览器）
3. 页面会自动解析并展示每个子文件夹的内容

## 🚀 部署方法

你可以将整个文件夹部署到以下平台：

- [Vercel](https://vercel.com) 
- [Netlify](https://www.netlify.com) 
- [GitHub Pages](https://pages.github.com) 

只需上传 `index.html` 即可运行！

> ⚠️ 注意：`webkitdirectory` 仅在 Chromium 浏览器中支持。
